## Présentation

Ajoute des boosts d'items dans une arène.

Utilisé sur : **Opale**.

## Commandes

| Commande | Alias | Description | Permission |
|---|---|---|---|
| `/shitemsboosts` | `/shib` | Commande principale du plugin SHItemsBoosts. | `shitemsboosts.admin` |

## Permissions

| Permission | Description | Par défaut |
|---|---|---|
| `shitemsboosts.admin` | Donne accès à toutes les commandes d'administration de SHItemsBoosts. | `op` |

## Configuration

Fichiers par défaut repris du serveur (secrets remplacés par `CHANGE_ME`) :

- `config.yml`

## Compilation

Java 17 et Maven :

```bash
mvn clean package
```

Le jar est généré dans `target/`.
